# 业财系统 · 工时归集 — In-product console demo

Light B-end 业财控制台原型（非营销页）。

## Open

```bash
cd apps/yecai-workhour-demo
npx --yes serve -l 5178 .
# http://localhost:5178/
```

Or open `index.html` directly.

## Screens

1. 周填报（品牌+品线+业务组+业务类型）
2. 我的填报（无拆分）
3. Leader 归集确认（左下角切换身份）
4. 项目人力报表
5. 品牌品线人力报表
6. 主数据来源说明（只读）
