## 1. 问题与目标

**问题：** 算不清每个项目、品牌品线的人力投入；填报人无法判断「该归哪个项目」，若强制填项目会失真。

**目标：**

1. 全员按周填**可判断维度**（营销部 / 品牌 / 品线 / 执行单类型两级 + 本周占比%）。
2. 系统做归集拆分到项目 / 执行单；**仅业务组 Leader** 可见并确认锁定。
3. 产出 **项目人力**、**品牌品线人力** 报表，供管理 / 财务查看。

---

## 2. 角色与权限

| 角色 | 能力 |
|------|------|
| 填报人 | **工时填报**、我的填报；**不见**拆分结果 |
| 业务组 Leader | 本组拆分确认 / 锁定 |
| 管理 / 财务 | 项目人力、品牌品线人力报表（成本列按字段权限） |
| 管理员 | 配置面板（部门人数、部门↔品牌映射）、填报进度面板 |
| 全员（Demo） | **配置**（部门↔负责人；默认来自人事系统，可本机编辑） |

---

## 3. 信息架构（侧栏）

```
人效 / 工时
  ├─ 工时填报          ← 原「周填报」；已移除「填报对比」
  ├─ 我的填报
  ├─ 待我确认
  └─ 配置              ← 部门 ↔ 负责人（HR 默认同步）
报表
  ├─ 项目人力
  └─ 品牌品线人力
管理 / 配置（仅 admin）
  ├─ 配置面板
  └─ 填报进度面板
说明
  └─ 主数据来源
```

顶栏另有 **观测台**（高管财务，见 `prd-observatory.md`），不占用本侧栏。

路由：`#fill` → 工时填报；`#config` → 配置（部门负责人）；旧 `#fill-cmp` **重定向到** `#fill`。

## 4. 界面清单与验收要点

| # | 界面 | 谁用 | 必须行为 |
|---|------|------|----------|
| 1 | **工时填报** | 全员 | 周状态条选 ISO 周；按营销部分块；**添加营销部**弹窗**多选**（始终列出一部–九部；已添加置灰标「已添加」；按钮「添加所选部门（n）」）；部门下多行：品牌→品线、执行单 L1→L2、占比%；行合计 **100%**；暂存 / 提交；已锁定周只读 |
| 2 | 我的填报记录 | 填报人 | 仅本人行与状态；**无**项目/执行单拆分列 |
| 3 | 归集拆分与确认 | Leader | 按业务组看系统拆分；确认后锁定纳入人效 |
| 4 | 项目人力 | 管理 / 财务 | 项目维度人天；周期筛选；财务可见成本列（权限） |
| 5 | 品牌品线人力 | 同上 | 业务组 → 品牌 → 品线；可筛营销部 |
| 6 | **配置** | 全员（Demo） | 查看/编辑营销部↔负责人；默认标注来自人事系统；暂存草稿 / 保存 / 恢复 HR 默认 |
| 7 | 配置面板 | 管理员 | 营销一部–九部员工数；部门→品牌多选；约束填报品牌下拉 |
| 8 | 填报进度面板 | 管理员 | 按周看提交进度；可切周 |

**已移除：** 填报对比（平铺 UX 变体）页面与菜单。

**主数据：** 不下放 CRUD。品牌品线、营销部、执行单类型两级均下拉引用既有主数据。

## 5. 填报周选择（状态条）

替换原顶部「填报周」下拉，改为横向 **周状态条**：

| 状态 | 含义 | 视觉 |
|------|------|------|
| 未填 | 该周无内容 | 灰点 |
| 暂存 | 有草稿 / 未提交完整 | 琥珀色点 |
| 已提交 | 已提交待锁定 | 主色点 |
| 已锁定 | Leader/系统锁定，不可再改 | 绿色点 |

- 展示可横滑的 ISO 周历史（Demo：`2026-W20`–`2026-W44`，约 25 周），含日期区间与状态文案  
- 左右箭头 / 触控横滑浏览更早或更新的周；当前选中周自动滚入视口  
- 点击切换当前填报周；当前周高亮  
- 图例与色点一眼可见各周进度（演示样例：W20–W29 已锁定、W30–W35 已提交）

## 6. 关键业务规则

1. **填报粒度：** 周；量为**占比 %**，同一周所有行合计须为 100%。
2. **维度顺序：** 营销部（业务组）→ 品牌 → 品线 → 执行单类型 L1 → 子类型 L2。
3. **拆分可见性：** 填报人不可见拆分；Leader 仅见本组。
4. **锁定：** Leader 确认后纳入人效统计；已锁定周不可暂存/提交。
5. **部门↔品牌：** 管理员配置映射后，填报品牌下拉受约束，避免跨部门串品牌。
6. **添加营销部：** 不按一部→二部顺序自动追加；弹窗始终列出九部，多选后一次性添加；已添加项禁用并标「已添加」。
7. **部门↔负责人：** 默认由人事系统同步；Demo 可本机覆盖；添加部门弹窗展示当前负责人。
