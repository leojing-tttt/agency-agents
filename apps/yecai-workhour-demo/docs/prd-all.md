---

## 1. 问题与目标

**问题：** 算不清每个项目、品牌品线的人力投入；填报人无法判断「该归哪个项目」，若强制填项目会失真。

**目标：**

1. 全员按周填**可判断维度**（营销部 / 品牌 / 品线 / 执行单类型两级 + 本周占比%）。
2. **部门 Leader** 审核本组周填报（确认后生效）；再经 **工时分配**：参考**上周支出比例**，编辑**上周分摊占比**（同属上期），再拆本周填报到项目，由**业务一号位**确认。
3. 产出 **基础报表**（原品牌品线人力）、**项目人力** 报表，供管理 / 财务查看。

---

## 2. 角色与权限

| 角色 | 能力 |
|------|------|
| 填报人 | **工时填报**；提交后待 Leader 审核，**确认后才生效** |
| 部门 Leader | **部门审核**：按周看本组填报人，确认 / 驳回 |
| 业务一号位 | **工时分配**确认（按上周分摊占比；参考上周支出比例） |
| 管理 / 财务 | 基础报表、项目人力（基础报表含人天与成本） |
| 管理员 | **配置**组（部门负责人、填报范围）；配置面板（部门人数、部门↔品牌映射）；填报进度面板 |
| 财务 / CFO | **配置**组：部门负责人、填报范围（组织树勾选须填报部门） |
| 其他角色 | 不显示侧栏「配置」分组 |

## 3. 信息架构（侧栏）

```
人效 / 工时
  ├─ 工时填报          ← 原「周填报」；已移除「填报对比」「我的填报」
  └─ 部门审核          ← 原「待我确认」；含二级「工时分配」
报表
  ├─ 基础报表          ← 原「品牌品线人力」
  └─ 项目人力
配置（财务 / 管理员 / CFO）
  ├─ 部门负责人        ← 原「配置」；部门 ↔ 负责人（HR 默认同步）
  └─ 填报范围          ← 组织树勾选须填「项目公示人力」的部门；负责人是否填报开关
管理 / 配置（仅 admin）
  ├─ 配置面板
  └─ 填报进度面板
说明
  └─ 主数据来源
```

顶栏另有 **观测台**（高管财务，见 `prd-observatory.md`），不占用本侧栏。

路由：`#fill` → 工时填报；`#review` → 部门审核；`#review-alloc` → 工时分配；`#config` → 部门负责人；`#fill-scope` → 填报范围；`#basic` → 基础报表；`#project` → 项目人力；旧 `#mine`/`#leader` → `#review`；旧 `#fill-cmp` → `#fill`。

## 4. 界面清单与验收要点

| # | 界面 | 谁用 | 必须行为 |
|---|------|------|----------|
| 1 | **工时填报** | 全员 | 周状态条选 ISO 周；按营销部分块；**添加营销部**弹窗**多选**（始终列出一部–九部；已添加置灰标「已添加」；按钮「添加所选部门（n）」）；部门下多行：品牌→品线、执行单 L1→L2、占比%；行合计 **100%**；暂存 / 提交；已锁定周只读 |
| 2 | **部门审核** | 部门 Leader | 按周列出本组填报人；**确认 / 驳回**；仅确认后填报生效 |
| 3 | **工时分配**（部门审核二级） | Leader 调分摊 / 一号位确认 | 列含**上周支出比例**（只读参考，合计100%）与**上周分摊占比**（可编辑、同属上期，默认=支出比例，合计须100%）；按该占比拆**本周**项目工时 |
| 4 | 项目人力 | 管理 / 财务 | 列：项目编号 → 项目 → 业务组名（营销部） → 品牌品线 → 业务类型汇总 → 投入人天 → 人力成本(元，财务可见)；周期/项目筛选 |
| 5 | **基础报表** | 同上 | 列：时间周期 → 业务组 → 品牌 → 品线 → 执行单类型 → 投入人天 → 成本；筛品牌/营销部/业务类型；**年份/月份快捷** + **周期多选**（可看某部全年成本）；点人天开抽屉 |
| 6 | **部门负责人** | 财务 / 管理员 / CFO | 查看/编辑营销部↔负责人；默认标注来自人事系统；暂存草稿 / 保存 / 恢复 HR 默认 |
| 7 | **填报范围** | 财务 / 管理员 / CFO | 公司组织架构多级树（mock `DepartmentDTO` / `getDeptTree`）；勾选须填「项目公示人力」的部门；开关「部门负责人是否需要填报」；保存本机 |
| 8 | 配置面板 | 管理员 | 营销一部–九部员工数；部门→品牌多选；约束填报品牌下拉 |
| 9 | 填报进度面板 | 管理员 | 按周看提交进度；可切周 |

**已移除：** 填报对比（平铺 UX 变体）页面与菜单。

**主数据：** 不下放 CRUD。品牌品线、营销部、执行单类型两级均下拉引用既有主数据。

## 5. 填报周选择（状态条）

替换原顶部「填报周」下拉，改为横向 **周状态条**：

| 状态 | 含义 | 视觉 |
|------|------|------|
| 未填 | 该周无内容 | 灰点 |
| 暂存 | 有草稿 / 未提交完整 | 琥珀色点 |
| 已提交 | 已提交待锁定 | 主色点 |
| 已锁定 | Leader/系统锁定，不可再改 | 绿色点 |

- 展示可横滑的 ISO 周历史（Demo：`2026-W20`–`2026-W44`，约 25 周），含日期区间与状态文案  
- 左右箭头 / 触控横滑浏览更早或更新的周；当前选中周自动滚入视口  
- 点击切换当前填报周；当前周高亮  
- 图例与色点一眼可见各周进度（演示样例：W20–W29 已锁定、W30–W35 已提交）

## 6. 关键业务规则

1. **填报粒度：** 周；量为**占比 %**，同一周所有行合计须为 100%。
2. **维度顺序：** 营销部（业务组）→ 品牌 → 品线 → 执行单类型 L1 → 子类型 L2。
3. **拆分可见性：** 填报人不可见拆分；Leader 仅见本组。
4. **生效：** 填报提交后为待审核；**部门 Leader 确认后才生效**；驳回未生效。已生效周进入工时分配。
4b. **工时分配：** 上周支出比例与上周分摊占比均属上期口径（支出只读、分摊可改且同来源须100%）；用分摊占比分配本周填报；一号位确认锁定。
5. **部门↔品牌：** 管理员配置映射后，填报品牌下拉受约束，避免跨部门串品牌。
6. **添加营销部：** 不按一部→二部顺序自动追加；弹窗始终列出九部，多选后一次性添加；已添加项禁用并标「已添加」。
7. **部门↔负责人：** 默认由人事系统同步；Demo 可本机覆盖；添加部门弹窗展示当前负责人。
8. **基础报表周期：** 列表带时间周期（ISO 周）；顶部年份/月份快捷圈选对应周，周期区可多选细调；mock 覆盖 2026 全年 52 周。

# 产品需求 · 观测台（CEO / CFO 高管财务）

| 项 | 内容 |
|----|------|
| 产品 | 业财系统 · 观测台 |
| 文档状态 | 与当前 Demo 对齐（顶栏一等入口，非侧栏财务菜单） |
| 受众 | 产品、研发、测试、AI 辅助实现 |
| 定位 | 高管日决策财务壳；样例数脱敏；非正式账面 |

---

## 1. 问题与目标

**问题：** CEO / CFO 每天要快速回答「赚不赚钱、钱进没进、哪条线在掉、有没有要拍板的异常」；不宜埋在普通 B 端表单侧栏里。

**目标：**

1. 提供顶层 **观测台** 体验：冷静财务感 / 可切换经典暖色；结构仍是产品 UI，不是营销站。
2. 四视图：总览、收入与贡献、回款与现金、成本与毛利。
3. 时间筛选、环比/同比、按客户/按品牌、口径公式可收起；贡献只展示数字（无条、无%）。

---

## 2. 角色与默认落地

| 角色 | 观测台 | 默认落地 |
|------|--------|----------|
| CEO | 可进 | 总览 |
| CFO | 可进 | 总览（Demo：切身份进总览；CFO 细节在回款/成本页更全） |
| 财务 | 可进 | 总览 |
| 管理员 | 可进 | 可进观测台；工作台仍有配置 |
| 填报人 / Leader | Demo：顶栏可点观测台 → **自动切 CEO** 进入（便于演示） | — |

正式产品中填报人 / Leader **不应**默认进入金额模块（字段权限）。

## 3. 信息架构

**入口（必须）：** 顶栏 **观测台**（始终可见），**不是**左侧「财务 / 日报」菜单。

进入后：

- 侧栏收起；出现观测台 rail：字标 + Tab（总览 / 收入 / 回款 / 毛利）+ 返回工作台
- 旧 hash 兼容：`#obs`、`#fin-overview`、`#fin-revenue`、`#fin-cash`、`#fin-margin`

**配色：** 顶栏 **配色 · 冷静 | 经典**（`localStorage: yecai-theme-v1`，默认冷静）。

## 4. 界面与能力

### 4.1 总览

- 时间：今日 / 近 7 天 / 近一个月 / 自定义区间
- 比较显示：环比+同比 / 仅环比 / 仅同比 / 不显示（与收入页同步偏好）
- KPI 条：确认收入、回款、成本、毛利、毛利率、待确认/异常
- 贡献：按品牌 | 按客户（仅金额+比较，无进度条/%）
- 待拍板：最多 3 条异常入口
- 口径 / 计算公式：可折叠（默认收起）
- 指标 `?` 提示：侧向弹出，不压死本卡标题

### 4.2 收入与贡献

- 快照日、执行单类型 L1、营销部筛选
- 同上比较显示与客户/品牌切面
- 明细表：金额 + 比较列

### 4.3 回款与现金

- 当日回款 / 未到期 / 逾期；账龄构成；当日流水（脱敏）
- CFO 可见更多明细列

### 4.4 成本与毛利

- 可归成本结构、品牌毛利
- **人力仅周锁定对照**，不伪造「今日工时成本」

## 5. 关键业务口径（Demo 约定）

| 项 | 约定 |
|----|------|
| 日快照 | T+1 财务确认视角展示 |
| 收入 | 执行单确认额（非开票额） |
| 环比 | 较上一可比周期（如较昨日） |
| 同比 | 较去年同日 / 同区间（样例需覆盖去年数据） |
| 客户 vs 品牌 | 不同切面；例：金佰利 ⊃ 好奇 + 高洁丝 |
| 人力 | 只引用已锁定周人天 vs 本周确认收入 |
