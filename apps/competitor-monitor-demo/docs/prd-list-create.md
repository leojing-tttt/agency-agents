# 产品需求 · 列表与配置

| 项 | 内容 |
|----|------|
| 产品 | A3 SaaS · 竞品投放监控 |
| 文档状态 | 与当前 Demo 对齐 |
| Demo | 列表页 + 新建/编辑 Modal |

---

## 1. 问题与目标

**问题：** 缺少统一入口管理「盯哪些竞品、用哪些词、多久抓一次、抓多少、怎么分层」。

**目标：**
1. 列表一眼看到监控任务健康度与规模。
2. 配置项足够支撑后端调度，且**每个竞品可不同**。

---

## 2. 列表字段

| 列 | 说明 |
|----|------|
| 竞品品牌 | 点击进详情 |
| 品牌词 | Tag 展示 |
| 抓取频次 | 每一周 / 每两周 |
| 单次上限/词 | 数字 |
| 状态 | 已更新 / 抓取中 / 失败 / 已停用 |
| 上次更新 | 本地时区展示（产品用业务时区） |
| 笔记数 | 去重后累计或最近批次（Demo 用累计） |
| 操作 | 查看 / 编辑 / 删除 |

工具栏：搜索品牌 +「新建竞品」主按钮。

---

## 3. 配置表单（Modal）

| 字段 | 必填 | 规则 | 默认 |
|------|------|------|------|
| 竞品品牌 | 是 | 非空字符串 | — |
| 品牌词 | 是 | ≥1；回车或「添加」；可删 | — |
| 抓取频次 | 是 | weekly / biweekly | biweekly |
| 单次抓取上限/词 | 是 | 整数 10–500 | 100 |
| 底部达人阈值 | 是 | 粉丝 `<` 该值 → 底部 | 10000 |
| 中腰部达人阈值 | 是 | 须 `>` 底部；`≥` 该值 → 头部 | 500000 |
| 启用自动抓取 | 否 | 开关 | 开 |
| 平台 | — | MVP 固定小红书，只读 | 小红书 |

**分层公式：**  
`fans < bottom` → 底部；`bottom ≤ fans < mid` → 中腰；`fans ≥ mid` → 头部。

---

## 4. 界面验收

| # | 必须行为 |
|---|----------|
| 1 | 无数据时空态文案 + 可新建 |
| 2 | 未填品牌或品牌词时不可保存 |
| 3 | 中腰阈值 ≤ 底部时不可保存并提示 |
| 4 | 删除需二次确认（Demo：危险色确认钮；产品：antd danger + Modal.confirm） |
| 5 | 编辑后列表与详情摘要同步 |

---

## 5. 关键业务规则

1. 品牌词按用户输入原样保存（不去空格语义改写）。
2. 修改分层阈值后，已有笔记应按新阈值重新计算分层（Demo 已做）。
3. 修改上限/频次从**下一调度周期**生效（后端契约）；Demo 仅存配置。

---
