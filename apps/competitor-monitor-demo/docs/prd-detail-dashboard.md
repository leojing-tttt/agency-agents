# 产品需求 · 详情与看板

| 项 | 内容 |
|----|------|
| 产品 | A3 SaaS · 竞品投放监控 |
| 文档状态 | 与当前 Demo 对齐 |
| Demo | 详情页三块看板 + 笔记表 |

---

## 1. 问题与目标

**问题：** 只有笔记流水不够决策；需要看到量级走势、达人结构、内容话术分布。

**目标：**
1. 摘要区复述配置与规模。
2. 三块看板：走势、达人金字塔、词云。
3. 下方笔记明细可核对。

---

## 2. 页面结构

1. 顶栏：返回 · 品牌名 · 状态 ·「编辑配置」
2. 摘要：品牌词 / 频次+上限 / 笔记数 / 互动合计
3. 看板区：
   - 左：走势图（笔记数 + 互动量，双轴）
   - 右：达人金字塔（底 / 中 / 头）
   - 下：内容词云（标题+正文）
4. 笔记表：时间、标题、作者、粉丝、分层、赞/藏/评、匹配词

---

## 3. 看板定义

### 3.1 走势

| 项 | 定义 |
|----|------|
| 横轴 | 抓取批次时间（Demo 用模拟双周点） |
| 纵轴左 | 该批次笔记数 |
| 纵轴右 | 该批次互动量（赞+藏+评） |
| 空态 | 尚无批次时展示空图或提示 |

### 3.2 达人金字塔

| 层 | 规则 |
|----|------|
| 底部 | `fans < tierBottomMax` |
| 中腰 | `tierBottomMax ≤ fans < tierMidMax` |
| 头部 | `fans ≥ tierMidMax` |

展示：每层篇数 + 占比。阈值文案在卡片标题旁展示。

### 3.3 词云

- 语料：笔记标题 + 正文（后端分词；Demo 用预设词权）
- 字号映射词频权重
- MVP 不做点击下钻

---

## 4. 界面验收

| # | 必须行为 |
|---|----------|
| 1 | 从列表点品牌名或「查看」进入详情 |
| 2 | 金字塔层数与当前分层配置一致 |
| 3 | 编辑配置改阈值后返回详情，分层标签更新 |
| 4 | 无笔记时笔记表与三块看板均为空态，不假装已抓取 |

---

## 5. 关键业务规则

1. 详情只读本竞品数据，不做多品牌对比。
2. 互动合计与走势「互动量」口径一致：赞+藏+评。
3. 匹配词：笔记命中的品牌词之一（多词命中时后端可返回数组；Demo 单值）。
