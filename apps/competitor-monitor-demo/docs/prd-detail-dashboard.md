# 产品需求 · 详情与看板

| 项 | 内容 |
|----|------|
| 产品 | A3 SaaS · 竞品投放监控 |
| 文档状态 | 与当前 Demo 对齐 |
| Demo | 详情页时间筛选 + 三块看板 + 笔记表 |

---

## 1. 问题与目标

**问题：** 只有笔记流水不够决策；需要看到量级走势、达人结构、内容话术分布，并按时间切片看规模。

**目标：**
1. 配置类信息（品牌词 / 频次 / 累计笔记与互动）收在「编辑配置」顶部，不占详情首屏。
2. 详情提供**发布时间**区间筛选，并展示区间内总笔记数、总互动量。
3. 三块看板 + 笔记表随时间筛选联动。

---

## 2. 页面结构

1. 顶栏：返回 · 品牌名 · 状态 ·「编辑配置」
2. **时间筛选条**：起止日期 + 重置；右侧 **区间笔记数** / **区间互动量**（赞+藏+评）
3. 看板区（均按筛选后的笔记/批次）：
   - 左：走势图（笔记数 + 互动量，双轴）
   - 右：达人金字塔（底 / 中 / 头）
   - 下：内容词云（标题+正文）
4. 笔记表：仅展示筛选范围内的笔记

配置摘要（品牌词 / 抓取频次 / 累计笔记数 / 累计互动）→ 见「编辑配置」Modal 顶部，仅编辑已有竞品时展示。

---

## 3. 时间筛选规则

| 项 | 定义 |
|----|------|
| 字段 | 笔记 `published_at`（业务时区 Asia/Shanghai） |
| 控件 | 开始日期、结束日期；闭区间（含起止当日） |
| 默认 | 进入详情时取该竞品笔记最早～最晚发布日；无笔记则当天 |
| 重置 | 恢复默认区间 |
| 校验 | 开始不得晚于结束 |
| 区间汇总 | 筛选后笔记条数；筛选后赞+藏+评之和 |
| 看板联动 | 笔记表、金字塔、词云、走势（按批次 `date` 落在区间内）均跟随筛选 |

---

## 4. 看板定义

### 4.1 走势

| 项 | 定义 |
|----|------|
| 横轴 | 抓取批次时间（Demo 用模拟双周点） |
| 纵轴左 | 该批次笔记数 |
| 纵轴右 | 该批次互动量（赞+藏+评） |
| 筛选 | 仅展示批次日期落在筛选区间内的点 |
| 空态 | 区间内无批次时提示 |

### 4.2 达人金字塔

按**当前筛选结果**中的笔记粉丝分层统计篇数与占比。

### 4.3 词云

- 语料：筛选范围内笔记的标题 + 正文（后端分词；Demo 有笔记时展示预设词）
- 区间无笔记 → 空态

---

## 5. 界面验收

| # | 必须行为 |
|---|----------|
| 1 | 详情首屏无品牌词/频次四宫格；打开「编辑配置」顶部可见累计摘要 |
| 2 | 改时间筛选后，区间笔记数与区间互动量即时更新 |
| 3 | 笔记表与金字塔只含筛选范围内数据 |
| 4 | 无笔记或筛空时各模块空态，不假装有数据 |

---

## 6. 关键业务规则

1. 详情只读本竞品数据，不做多品牌对比。
2. **区间互动量**与配置里「累计互动」口径一致（赞+藏+评），但统计范围不同。
3. 匹配词：笔记命中的品牌词之一（Demo 单值）。
