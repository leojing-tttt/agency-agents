# 业财 · 液态系统 — Product Design Demo

Interactive product demo for Project **业财** liquid system (液态系统).

## Open

No build step. Serve the folder or open the file:

```bash
cd apps/liquid-system-demo
npx --yes serve -l 5177 .
# then open http://localhost:5177/
```

Or open `index.html` directly in a browser.

## What’s inside

Single-file interactive walkthrough: hero → conversational liquid thread → event→voucher morph → rule reshape → audit trail.
