# 功能列表（打标 + 管理）

## 1. 维度管理（标签类型管理）

- 查看所有维度及其枚举（id + 中文名）
- 新增枚举（例如渠道增加「永辉」）
- 删除枚举（必填维度至少保留 1 个）
- 词表版本号（`taxonomy.version`）
- 开放字段配置：`scene_tags`、`ocr_text` 上限
- 场景同义词归并（爬山→登山）
- **不管理**产品品牌维度（产品上传前已选）

数据文件：`data/taxonomy.json`

## 2. 映射表管理（图片类型叶子 → 大类）

- 查看大类列表
- 查看 / 修改「叶子枚举 → 大类」
- 与 `image_type` 维度交叉校验：
  - 每个叶子必须有映射
  - 不能映射到不存在的大类
  - 不能残留词表里已删除的叶子
- 映射版本号（`mapping.version`）

数据文件：`data/image_type_category_map.json`

## 3. 打标执行

- 强制先带 `product_id` / `product_name`（及可选 knowledge_id）
- 扫描 inbox 图片批处理
- **单次**本地视觉模型调用，输出全部封闭维度
- 程序校验枚举；非法或低置信度 → `needs_review`
- 自动附加 `image_type_category`（来自映射表，非模型输出）
- 导出 JSONL + 待审 CSV
- 文件哈希去重字段（`image_sha256`，便于后续跳过）
